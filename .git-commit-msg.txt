feat: ExcelFinder — 本地 Excel 极速检索，精确到单元格

一个免安装的单文件 Windows 程序，为目录中的 Excel/CSV 建立内存索引，
按关键词毫秒级检索，并定位到「工作表 + 单元格」。

核心设计
- 两段式定位：索引只回答「哪个文件命中」，单元格坐标按需二次解析
  （预存全部坐标会让内存翻数倍；实测第二遍仅 3.3 ms/文件）
- 直接解析 OOXML 内部 XML（sharedStrings / worksheets），零第三方依赖，
  比 pandas / openpyxl 快约一个量级，单文件 exe 仅 12.6 MB
- 顶层目录切分为独立子树多线程扫描；缓存 (路径, 大小, 时间) 支持增量复扫
- 内容小写形式缓存复用，避免每次查询重复 casefold 几十 MB 文本

功能
- 文件名 / 内容双范围检索，空格分隔 = AND，支持通配符与正则
- 命中位置列显示「工作表!单元格」，双击用 Excel / WPS 打开并跳转选中
- 打开方式可选 自动 / 仅 Office / 仅 WPS（注册表探测，不靠启动进程试探）
- 刷新列表 (F5)：增量重扫目录并重跑当前查询，状态栏报告增删变化
- 分阶段进度条；索引缓存超过 256 MB 不再落盘
- U盘便携模式：配置与索引存于程序旁 data 目录，不污染宿主机器

质量保障
- tools/build.py 一键流水线（9 步，含打包与全量验证）
- 验证覆盖：引擎基准、真实 GUI 集成、刷新增删文件、便携包端到端、
  Win32 窗口枚举、与 where.exe / PowerShell / Windows 搜索的性能对比
- tools/prune_embed.py 用「隔离候选 + 实际启动 GUI」的方式裁剪内置运行时，
  避免凭猜测删除导致打包产物无法运行
